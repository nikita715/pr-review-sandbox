# Правила ревью

## Что важно в этом проекте
- Деньги хранятся только в целых центах (`*_cents: int`), никаких `float`.
- Все SQL-запросы — только с параметрами (`?`), без форматирования строк.
- Резервирование товара в заказе атомарно: при ошибке в любой позиции
  остатки не меняются.
- Порядок расчёта итога: сумма позиций → скидка → налог.

## Что не комментировать
- Форматирование и порядок импортов.

## Конвенции
- Только стандартная библиотека Python, без внешних зависимостей.
- Ошибки бизнес-логики — через `OrderError`.
- Новая логика покрывается тестами в `tests/` (unittest).
